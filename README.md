# PEPROF 166 — Complete GitHub Course Source

**Status: instructor review source; NOT an importable IMSCC.**

This unified package includes **Start Here**, **Module 1**, **Modules 2–10**, and **all assignment records present in the supplied Canvas export**. The original course export is the source of truth for assignment metadata; revised HTML files are separate working drafts.

## Folder guide
- `Start_Here/`: five Canvas page drafts and instructions.
- `M01/`: developed Module 1 draft pages, philosophy workspace assessment, optional alternative and instructor practice.
- `M02/`–`M10/`: student-facing draft pages, optional reflections, instructor-only quiz keys and source-review notes.
- `source-reference/exported-assignments/`: exported assignment HTML descriptions and `assignment_settings.xml` (when available), **unmodified**, for reconciliation. Includes both active and unpublished items; do not publish all of them.
- `ASSIGNMENT_INVENTORY.csv`: title, publication state, points, submission types, and source folder for each exported assignment.
- `AUDIT_AND_IMPORT_PLAN.md`: conversion and verification steps.

## Required review before import
1. Resolve duplicate active versus unpublished redesign items. Verify the Module 1 Teaching Philosophy workspace and Module 2 Teacher Interview assessment.
2. Review each source assignment's title, instructions, points, due dates, submission type and rubric. Do not replace a graded item with an optional reflection without instructor approval.
3. Keep instructor-only answer keys and restricted materials private. Do not turn on GitHub Pages for the entire repository.
4. Test Canvas HTML in a sandbox. Gradients may be sanitized; use solid purple as fallback.
5. Generate a valid Common Cartridge with a manifest, resource references and Canvas-compatible module/assignment/quiz structures. **Do not rename this ZIP to `.imscc`.** Test import into a blank Canvas sandbox and verify content, links, quizzes, rubrics and publication states.

Design: UW–Whitewater Digital Learning Design 2.0; purple-to-violet headers, white and neutral gray, no gold, optional text-only Willie hints. Freshman-friendly writing and instructor-neutral language. No live Canvas changes have been made.
