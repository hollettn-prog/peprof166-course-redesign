Health Skills Portfolio: Build, Test, Improve

This three-week, 100-point project is your professional teaching toolkit. Open the Health Education Skills assignment site and review the directions for all seven skills.

Phase 1: Plan

Map each artifact to a learner/context, standard, skill cues, modeling, guided practice, feedback, independent application, evidence, and access/privacy support. Use this map as a checkpoint before completing all seven products.

Phase 2: Build

Create a usable first version of each artifact. Prioritize instructional value, clarity, and alignment over decoration.

Phase 3: Test

Use the rubric and available peer or instructor feedback to test at least one representative artifact. Identify one strength, one risk, and one question a future user might have.

Phase 4: Improve and curate

Revise the artifact and include a short revision note: what changed, what evidence prompted the change, and why the new version better supports learners. Organize the complete set so another educator can understand when and how to use it.

Quality criteria

  • Accurate alignment to the health skill and standard
  • Clear model, meaningful practice, and actionable feedback
  • Evidence that measures skill development
  • Developmental fit, accessibility, cultural responsiveness, privacy, and learner choice
  • Professional clarity and practical usefulness
