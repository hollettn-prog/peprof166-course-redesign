# Audit and import plan

The `ASSIGNMENT_INVENTORY.csv` lists source assignment records from the Canvas export. The `source-reference` directory preserves their original HTML and settings for comparison. Some are duplicates, drafts, or unpublished. They are **not automatically approved for inclusion in the final course**.

Before IMSCC conversion: choose authoritative module sequence, map each draft to a verified existing item, confirm discussion versus assignment types, points, rubrics, due dates, external tools, instructor videos, permissions, and content licensing. Never put instructor-only keys in student pages. Run accessibility checks and a sandbox import. Exported quiz definitions and file attachments may require separate reconciliation beyond this source package.
